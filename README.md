## 📅 Day 1

Topics covered today:

- List Comprehension
- Lambda Functions
- `map()` function
- `filter()` function

### What I Learned:

1. **List Comprehension** — writing a normal `for` loop in a single line, such as filtering numbers divisible by a certain value, or filtering elements from a list of strings based on a condition.
2. **Lambda** — writing small anonymous functions, such as checking if a number is a palindrome.
3. **map()** — applying a function to an entire list (e.g., converting strings to uppercase, or converting Celsius to Fahrenheit).
4. **filter()** — filtering elements from a list based on conditions (e.g., positive numbers, words starting with a vowel, odd numbers).
